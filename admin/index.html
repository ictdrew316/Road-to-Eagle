1Connect to GitHub

Each admin uses their own GitHub personal access token, scoped to just this repo. Nothing here is sent anywhere except GitHub's API — your token stays in this browser only.
Need a token? On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Set Resource owner to this repo's account, Repository access to only this repo, and under Permissions grant Contents: Read and write. That's the only permission it needs.
